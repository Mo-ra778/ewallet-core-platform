# 💳 نظام المحفظة الإلكترونية (E-Wallet Core Platform)

منظومة مالية ومصرفية رقمية متكاملة تعتمد على معمارية العميل والخادم (Client-Server Architecture)، توفر بيئة آمنة لإدارة الحسابات، وتداول الأموال، مع دعم كامل لعمليات الإيداع والسحب النقدي المباشر عبر شبكة وكلاء معتمدين (Cash-In / Cash-Out) ورقابة إدارية صارمة.

---

## 🌟 الميزات الرئيسية (Key Capabilities)

* 🛡️ **نظام مصادقة وأمان مشفر (JWT Authentication):** حماية كاملة لجميع الروابط والـ REST APIs باستخدام Bearer Tokens مع دعم الصلاحيات وحالات الحسابات.
* 👥 **رقابة واعتماد الحسابات (Account Verification Flow):** جميع حسابات العملاء الجديدة تنشأ بحالة معلقة (`pending`) وتتطلب موافقة وتفعيل من إدارة النظام قبل تنفيذ أي حركة مالية.
* 🏧 **سحب نقدي آمن بخطوتين (2-Step OTP Cash-Out):** آلية مؤمنة للوكيل تمنع سحب الكاش إلا بعد التحقق من كود OTP يتم توليده وإرساله لتطبيق العميل بصلاحية 5 دقائق.
* 💱 **تعدد العملات (Multi-Currency Support):** دعم العمليات المالية والتقارير بكافة العملات الرئيسية (`SAR`، `YER`، `USD`، `EUR`).
* 🔒 **سلامة المعاملات والامتثال المالي (ACID Compliance):** جميع العمليات المالية (إيداع، سحب، تحويل، تسوية إدارية) مغلفة برمجياً داخل `DB::transaction()`.
* 🎨 **واجهات مالية مؤسسية (Pure Light FinTech Design):** واجهات Blade مبنية وفق أحدث معايير المنتجات الرقمية المصرفية بنمط فاتح صافٍ، وسرعة استجابة عالية.

---

## 🛠️ البنية التقنية (Tech Stack)

* **الإطار الخلفي (Backend):** Laravel 13 (PHP 8.5)
* **المصادقة (Auth):** `firebase/php-jwt` (v7.1)
* **قاعدة البيانات (Database):** SQLite / PostgreSQL (باستخدام معرّفات UUID لكافة الجداول)
* **المؤقتات وذاكرة الكاش (Cache):** Cache Driver لإدارة أكواد التحقق (OTP)
* **الواجهات (Frontends):**
  * **بوابة الوكلاء (Agent Web Portal):** Server-Side Blade + Tailwind CSS
  * **لوحة تحكم الإدارة (Admin Dashboard):** Server-Side Blade + Tailwind CSS
  * **تطبيق الموبايل (Flutter):** يتواصل مع الـ REST APIs

## 🚀 دليل التثبيت والتشغيل المحلي (Local Setup Guide)

### 1. المتطلبات الأساسية:

* PHP >= 8.2 (مع تفعيل `pdo_sqlite`, `openssl`, `curl`, `mbstring`, `fileinfo`)
* Composer >= 2.2

### 2. تثبيت الحزم وإعداد البيئة:

```bash
# الانتقال لمجلد الباك إند
cd ewallet-backend

# تثبيت مكتبات الاعتماد
composer install

# إنشاء ملف البيئة
cp .env.example .env

# توليد مفتاح التطبيق ومفتاح JWT
php artisan key:generate
```

### 3. ترحيل قاعدة البيانات وملء البيانات التجريبية:

```bash
php artisan migrate:fresh --seed
```

### 4. تشغيل خادم التطوير:

```bash
php artisan serve
```
